# v1.2.1 音视频播放修复

账号测试已生成有效产物，但页面使用认证下载得到的 `blob:` 地址播放。原 CSP 没有 `media-src`，浏览器回退到 `default-src 'self'`，拦截音频和视频并显示 0:00。图片已有单独的 `img-src`，不受这项问题影响。

本次在默认策略、示例配置和运行时旧策略补全中加入 `media-src 'self' blob: data: https:`。允许本地认证预览、已有内联产物及 HTTPS 媒体，不扩大脚本来源。播放失败时展示独立提示和下载入口，重新查看记录不重新提交生成。测试日志也改为显示实际媒体提示词。

真实渠道核验复用用户已提交的 Omni 4 秒、Veo 8 秒和 Lyria 音频产物，认证预览接口返回的内容与服务器文件一致。浏览器复现原策略拦截；仅在测试浏览器响应中补齐策略后，Omni 和 Lyria 可读取时长、成功播放且播放时间前进。本轮不新增收费生成请求。部署后还需在真实响应策略下复核播放。

三个正式入口均纳入自动部署上线检查：

- https://code.aicodeme.cn
- https://code.aicodeme.xyz
- https://hkcode.aicodeme.xyz

发布后请刷新已有页面，再打开原测试记录；无需再次生成。`tests/latest` 的 404 表示账号尚无保存的测试记录，前端将其视为空状态，与媒体 CSP 拦截无关。
