# Sub2API v1.3.25

修复图片、音频、视频渠道监控对受理未知任务的误判、重复 pending 样本和耗时记录问题。未知受理结果继续核对同一上游任务，终态复用稳定样本 ID；历史写入成功后才推进最近检测时间。

- 媒体联调检测会按当前分组自动匹配登录用户自己的有效 API Key，优先使用最近使用的密钥，不再要求每次粘贴或选择。
- 管理员可以从任务详情一键核对已记录的上游任务；操作只查询原任务，不重复提交生成。历史任务的重新测试打开全新表单；联调页的重测会清空旧参数、素材和幂等 ID。
- 保留 v1.3.24 的模型检测阈值、异步任务和历史数据显示行为。本版本不发起新的付费生成验收，v1.3.24 的真实渠道结果继续作为历史基线。
- PostgreSQL、Redis 和容器资源预算保持现状；容量切换仍需满足七天采样、隔离恢复及 1.5 倍峰值负载门禁。

验证：渠道监控服务单元测试、PostgreSQL 历史写入集成测试、媒体联调与任务详情组件测试、前端类型检查、ESLint 和生产构建通过。正式发布工作流仍执行完整仓库检查、镜像启动和恢复演练。
