## 已修复的本站缺陷

1. 适配器仅在 HTTP 非 2xx 响应中提取结构化错误，并只从 HTTP 响应头提取请求编号。生产失败发生在 HTTP 200 的任务正文，导致错误码和正文中的请求编号丢失。v1.3.9 对模板、兼容协议的明确失败结果提取嵌套错误，保留真实传输状态 200，并在诊断中记录；保持不自动重提任务。
2. 管理端优先展示初始提交的 `queued` 响应，遮蔽了已保存的最终失败查询响应。v1.3.9 保留提交证据，同时独立展示最新任务响应；历史错误无需改数据库即可查看。

覆盖回归测试包括：HTTP 200 失败元数据、模板及兼容协议、超过 8 KiB 的查询正文、请求编号响应头优先与正文回退、脱敏和长度控制、成功任务不误判，以及初始受理和最终失败证据的独立展示与复制。
