# Sub2API v1.3.21

本版本包含 `v1.3.20` 的上游 `Wei-Shaw/sub2api` `v0.2.19` 合并内容、媒体功能兼容改动和依赖安全修复，并修复生产管理器升级包与旧版本引导器的兼容问题。

- 保留管理员 API Key、按图片张数计费、GPT-6.1 Terra、Gemini 重试配置和 Grok 模型目录诊断等上游功能。
- 发布管理器归档保持旧生产引导器可验证的成员清单；容量采集工具和 Compose 资源模板在安装脚本内校验后恢复，继续供后续基线采集和容量调整使用。
- 新增迁移 `253_scoped_admin_api_keys.sql` 和 `254_group_image_count_billing.sql`。正式部署管理器会在生产切换前备份并隔离恢复验证，再核对迁移校验和；不要手工执行 SQL。
- 生产容量调整仍需先完成七天峰值观测、备份隔离恢复和 1.5 倍负载验收，不包含在本次应用版本切换中。

真实渠道探测结果及部署前置状态见 `CHANNEL_VERIFICATION_CURRENT.json`；HTTP 502 的失败请求不表示生成成功，也不代表候选版本已在生产运行。
