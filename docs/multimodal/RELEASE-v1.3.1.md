# Sub2API v1.3.1

多媒体模型能力页面的“官方参考价 $”支持管理员在模型行直接编辑，按分组和公开模型名保存美元金额与计价单位。支持清空、刷新后读取和版本冲突检查；冲突时保留草稿，刷新当前内容后由管理员再次保存。匿名与普通用户只读，专属分组仍沿用原有可见性。

参考价仅为展示信息，存放在已有 settings 展示元数据中，与能力说明共享事务版本。不修改实际售价、倍率、计费规则、协议模板或已有任务，不增加数据库迁移。

侧栏与页面标题统一为“多媒体模型能力”“多媒体接口文档”。移除两页内容区的重复标题及说明，文档区域使用释放的高度，加载提示不占据额外行。用户和管理员侧栏加入“模型广场”，遵循现有模型广场开关；匿名媒体导航同步提供入口。

回归覆盖管理员写入权限、金额校验、分组隔离、保存及清空、并发冲突、能力说明与参考价互相保留、美元展示不应用实付倍率，以及公开页面路由。正式发布流水线完成镜像校验和隔离恢复演练后，按授权立即切换生产，不等待空闲。切换期间在途连接可能短暂中断，数据服务保持运行；生产验收证据在上线后补充。
