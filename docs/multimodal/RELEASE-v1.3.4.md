# Sub2API v1.3.4

媒体渠道检测现在能从网关包装响应中识别明确的上游 429 拒绝，并按 `Retry-After` 安排后续检测。普通 502、超时和其他受理状态不明的情况继续查询原任务或等待管理员核对，不会自动重复提交；无法恢复的请求可在管理员核对后显式重置。检测结果会在客户端请求中断后继续写入记录，管理员可查看历史结果；明确拒绝的下次提交仍在单独检测请求中发生。

媒体账号模型列表新增实际生效协议模板和继承来源。协议模板编辑区重新分组，并为常用字段与参数规则补充填写说明、格式和示例。

用户列表把主体数据加载与非关键字段并行获取，平台额度查询改为按当前页批量读取，避免逐用户请求。香港入口改用可复用的源站连接，为 JSON API 和静态内容协商压缩，并仅缓存带内容哈希的静态资源；HTML、API 和流式请求不缓存，SSE 保持关闭缓冲。

本版本不新增数据库迁移，也不修改现有媒体模板和模型配置。
