# v1.2.8 媒体文档编辑器修复

编辑器使用的 Axios 客户端已设置 `/api/v1` 为根路径；原组件再次传入 `/api/v1/admin/docs/imagevideo`，使实际请求变成 `/api/v1/api/v1/admin/docs/imagevideo`，生产 Nginx 日志证实返回 404。数据库文档与标准管理接口正常。

组件改用 `/admin/docs/imagevideo`，读取、历史、草稿、发布和回滚沿用客户端认证与响应处理。错误通过现有公共工具提取可读消息；初次读取失败时禁用编辑、保存与发布，刷新成功后恢复。版本冲突保留本地编辑内容。同步初始文档种子中的价格说明，不覆盖生产已发布内容。

回归测试使用真实 Axios 客户端、自定义传输适配器及真实拦截器，验证最终路径仅有一层 `/api/v1`、认证请求头、草稿隔离、预览消息、发布/回滚版本、409 冲突保留编辑、读取失败禁用与重试恢复。三个相关测试文件共 38 项通过；类型检查和修改文件 ESLint 通过。Docker 构建额外执行国际化检查、前端生产构建和嵌入式后端编译。

本补丁不新增数据库迁移，不更改计费与历史媒体任务，不发起收费生成。

v1.2.8 已部署成功，发布提交为 `24be1b4c9f3f2fe68280e234e981e41e3f2515df`。生产三个域名及本机健康、版本、镜像、文档 API、权限和备份恢复核验通过，PostgreSQL、Redis、定价服务未重启。切换观测到短暂不可用，随后恢复；采样无法确定精确停机时长。

浏览器已确认编辑器加载 23 章正文和版本历史，请求只有一层 `/api/v1`。验收使用隔离的测试会话壳和真实生产管理员 API Key 传输，不代表真实管理员 JWT 登录验收。管理员密钥只保留在本机转发进程内存，不写入截图或证据。

生产浏览器另发现 Nginx 的继承 `X-Frame-Options: DENY` 拦截文档预览。文档 location 增加同源 iframe 许可，并保留 HSTS、nosniff 和外站嵌入限制；管理器兼容迁移旧配置，并在校验/重载失败时恢复文件。此项作为独立基础设施补丁，不重打 v1.2.8 标签或镜像。部署工具增补升级、未知配置拒绝和失败恢复覆盖，共 54 项通过。

配置补丁 `5ff7cb371e18a4f43821f085d9d5814f7a98dd1f` 已安装为管理器 `7bfd3e8b816555f8`。持有现有操作锁后备份配置和入口脚本、核对源码哈希，再校验并平滑重载 Nginx。文档返回 `SAMEORIGIN` 与 `frame-ancestors 'self'`，主后台仍为 `DENY`；所有运行容器的 ID 和启动时间在此项操作前后一致。

最终生产浏览器验收通过加载、历史、预览、保存和发布。临时预览标记仅留在浏览器内存，恢复后以完全相同的正文保存和发布，文档版本由 v3 经草稿 v4 变为公开 v5；公开正文及草稿哈希与发布前基线一致。公开接口立即读取 v5，未重启容器。回滚和版本冲突由自动测试覆盖，本次未在生产点击回滚。桌面 1440×1000 与手机 390×844 均已检查，截图在等待布局过渡完成后保存。
