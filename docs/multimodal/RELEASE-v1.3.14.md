# Sub2API v1.3.14

修复多媒体文档联调在不完整能力目录下崩溃的问题，并补齐管理端视频测试的实际提交、回查和成品预览流程。

- 能力目录中的可选列表或素材配置为空时，模型选择和参数表单仍正常渲染；覆盖截图中 `Cannot read properties of null (reading 'length')`。
- 图片、视频和音频素材可多选上传、分批追加或直接拖入；按目录检查类型、数量及文件大小，并可逐项移除。
- 管理端联调先免费预览映射参数和估价，再由管理员明确确认后提交一次实际请求；保留幂等 ID、请求变化保护和同任务恢复查询，避免不明确时重复计费。
- 实际测试结果展示任务状态、入站及上游映射参数、提交响应、上游结果和联调日志；支持预览或下载生成的图片、视频和音频。
- 不新增数据库迁移；不会导入测试配置或自动发起供应商生成。

验证和部署结果见 `VALIDATION-v1.3.14.md`。
