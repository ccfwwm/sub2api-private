# Sub2API v1.3.23

本版本为 OpenAI API Key 图片请求新增账号级参数适配，并扩展渠道检测的生图预设和自定义接口能力。

- 在账号“图片请求参数适配”中删除 `response_format` 等不兼容字段，或配置 `size=resolution` 这样的参数改名。实际转发与账号测试共用规则，支持 JSON 和 multipart；未配置时保持现有行为。
- OpenAI、Gemini 和 Grok 新增图片生成检测，识别图片返回内容。
- 自定义检测支持请求方法、接口相对路径、JSON 请求体、请求头、响应 JSON 路径和非空判定，保留 endpoint 与拨号阶段的 SSRF 校验。
- 图片和自定义检测默认仅手动运行，周期检测需要明确启用；旧监控默认继续使用文本检测。
- 迁移 255 仅为监控和请求模板新增配置列，旧迁移校验和不变。部署工具校验精确 SQL，并在隔离恢复中验证旧数据、新默认值及旧镜像兼容性。

已通过前端回归、类型与构建检查，Go 全量单测、集成测试及静态检查，以及部署工具、镜像启动和备份恢复演练。本版本未提交新的真实渠道生图请求；历史渠道验证仅作为基线保留。

使用说明见 [图片参数适配与监控探测](../IMAGE_PARAMS_AND_MONITOR_PROBES_CN.md)。
