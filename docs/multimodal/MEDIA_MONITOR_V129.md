# v1.2.9 分组媒体检测与内置价格同步

2026-10-16 生产监控 17 的模型配置为 `gpt-image2.5`，分组白名单实际提供 `gpt-image-2.5`。首次请求在模型准入阶段返回 404 `model_not_allowed`，未到达生成服务。旧监控将明确拒绝和受理不确定统一存为 blocked，后续两毫秒内读取记录并返回笼统提示，掩盖真实原因。

修复保留脱敏后的 HTTP 状态、错误正文中的 message 和失败状态，并写入加密任务记录；再次检测和服务重启后仍展示相同原因。对于 5xx、网络中断等受理不确定的请求，继续保留防重复提交机制。配置页提示模型 ID 必须与 Key 的 `/v1/models` 完全一致，提示常见 GPT 图片连字符错误；结果弹窗增加编辑配置入口并修复窄屏换行。

线上监控改为 `gpt-image-2.5`，复用实际媒体账号的能力配置。既有启用监控随配置保存自动执行，25.117 秒取得有效图片，状态 operational；对应媒体任务已完成。历史检测记录保留。

生产外挂 `sub2api-pricing-overlay` 只用于目录同步及 16 项国产模型价格覆盖。移除时将覆盖文件转入 `/app/data/pricing/domestic-pricing-overrides.json`，使用 sub2api 自带 `PRICING_OVERRIDE_FILE`，目录及哈希恢复上游 HTTPS 地址。保留既有模型价格、渠道价格和分组倍率；移除 Compose 服务及启动依赖。数据库、Redis 和文档内容不做变更。

部署管理器只将 PostgreSQL、Redis 列为必须存在的保护容器，不再依赖已移除的外挂容器。旧配置和覆盖文件保留备份，以便回滚。
