# Sub2API v1.3.20

本版本合并上游 `Wei-Shaw/sub2api` `v0.2.19`，保留项目的 `v1.x` 发布版本体系和既有媒体任务、计费及部署管理能力。

- 新增可按操作和资源范围授权的管理员 API Key，支持有效期与 IP 白名单；服务端仅保存密钥摘要，并保留撤销审计记录。
- OpenAI 和 Composite 分组新增按实际生成图片张数计费选项，默认关闭，仅用于专用图片生成端点。
- 新增 GPT-6.1 Terra 模型支持。
- Gemini 同账号重试次数可通过 `gateway.max_same_account_retries_gemini` 配置，默认 4 次，可设为 0 至 10 次。
- Grok 账号管理增加模型目录诊断，可查看目录来源、可信状态及本地映射差异；手动同步和后台观察共用解析规则。
- 更新 Gemini 默认模型目录，并修复图片用量计费、分页偏移溢出、模型目录并发覆盖及多条协议兼容问题。
- 新增迁移 `253_scoped_admin_api_keys.sql` 和 `254_group_image_count_billing.sql`。图片按张计费默认关闭；正式部署管理器会先备份并隔离恢复验证，再核对迁移校验和后应用，不要手工执行 SQL。

本版本内置容量采集与报告工具及 Compose 资源覆盖模板。模板不预设线上机器规格或连接池参数；生产容量调整应在完成容量基线、恢复演练和负载验收后单独实施。
