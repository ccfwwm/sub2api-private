# Sub2API v1.3.19

修复 Foxrouter `gemini-omni-flash` 参考图协议映射，并让媒体联调可直接提交真实请求；修正文档侧栏版本徽标。

- 为 Foxrouter 模型提供独立的视频协议模板。入站 `images` 图片对象数组会按 MIME 转为 Base64 Data URL 字符串数组，放入上游 `Alias.images`；只在该模型绑定此模板，不改变其他上游的图片结构。
- 免费预估、实际绑定检查、付费提交各自独立运行。真实请求不再依赖先完成预估，预估运行时也不阻塞提交；任务恢复复用已冻结的原请求和幂等 ID。
- 预估和提交状态、错误与日志分开显示；原始请求及映射证据默认折叠。
- 文档侧栏版本徽标优先读取当前站点公开设置，并在该入口不可用时回退到直连接口。

`gemini-omni-flash` 的账号专属模板选择和生产验证见 `VALIDATION-v1.3.19.md`。
