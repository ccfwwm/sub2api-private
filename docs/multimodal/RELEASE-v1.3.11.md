# Sub2API v1.3.11

修复参考图片、视频和音频的默认素材透传，并完善模板配置、预览联调与在线接口文档。

- 默认保留素材原有的 `url` 或 `b64_json` 定位字段和值，以及素材顺序、MIME、角色和附加属性；不再把 Base64 字段改写为 URL。只有模板显式配置编码、结构、对象属性映射或精确过滤时才执行对应变换。
- 模板编辑器支持嵌套对象路径映射和过滤，并说明默认透传行为；素材映射使用克隆数据，避免改写任务中的原始请求快照。
- 支持显式配置嵌套属性值映射和字符串、数字、整数、布尔类型转换；保留裸 Base64 对象的 MIME 提示，避免视频和音频在预览或实际请求中被误拒。
- 新请求在账号预算与账务预留事务中取得提交租约，直接向上游提交后返回任务，去掉“先在本站排队等待两个 worker”路径。后台默认 128 个有界并行 worker，负责查询、恢复和旧任务提交；`SUB2API_MEDIA_WORKERS` 可设为 1–256。worker 先取得槽位再领数据库租约，避免本地内存排队及租约空耗。新请求提交不受后台 worker 数限制。
- 保留公开任务状态和既有接口，增加 `submission_phase` 区分本站待提交、提交上游、已受理和核对；任务列表不再把这些阶段统一显示为排队中，并记录提交耗时日志。
- 管理端预览联调增加独立提示词、图片/视频/音频文件上传转 Base64、输入和映射输出、估价及脱敏日志。预览仍不创建任务、不扣费、不调用上游生成接口。
- 公共在线调试器支持图片、视频、音频上传与 Base64 对象；接口文档按 OpenAI 图片、Gemini 图片、视频和音频四类归档，将 Grok 视频内容并入视频分类。
- 无新增数据库迁移，不修改已有任务记录或模板历史快照。

本版本通过本地单元/组件/文档校验，以及隔离 PostgreSQL 与模拟上游验证并行提交和幂等保护；仅对现有生产任务执行只读查询与制品 Range 校验，不提交真实生成请求。
