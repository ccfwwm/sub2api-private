# Sub2API v1.3.13

完善媒体账号模型测试与协议模板的当前配置管理，继续修复媒体管理和在线联调体验。

- 媒体账号编辑与测试弹窗使用完整工作区宽度，模型配置卡片为媒体类型和启用操作保留空间，窄屏下字段可换行。
- 测试按公开模型 ID 选择账号能力，实际请求使用该能力配置的上游模型；测试界面同时显示两者。新增回归覆盖映射模型解析及上游请求。
- 协议模板只有当前配置，不显示 v1/v2/v3 或历史备份；账号和监控的旧模板引用自动跟随当前配置。删除模板会停用关联模型，并把关联媒体监控降为连接检查；已受理任务继续使用提交时快照。
- 协议模板支持新增、修改标题和介绍、直接保存、复制独立模板及删除。保存不会新增历史备份记录，并阻止过期编辑覆盖当前内容。
- 预览和真实测试使用中转 API Key，支持有效 Key、用户与真实分组校验，不要求查询数据库 Key ID。
- 联调和文档支持多张图片、视频与音频上传，可逐批追加并逐项删除，校验 MIME、大小和数量；在线文档可选择模型、校验请求并估价，显示脱敏请求信息。
- 媒体模型与新媒体账号默认并发 100、查询间隔 10 秒。无新增数据库迁移。
- 保留 v1.3.11 后的视频原文件下载路径修复。

测试结果和生产切换记录见 `VALIDATION-v1.3.13.md` 与 `CHANNEL_VERIFICATION_CURRENT.json`。模拟上游验证不代表真实供应商生成验收。
