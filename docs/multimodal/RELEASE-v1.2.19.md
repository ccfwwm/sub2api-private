# Sub2API v1.2.19

修复 V6K 普通参考图对象携带 `role: reference` 导致上游拒绝请求的模板适配缺口。新增按字段和精确值过滤素材属性的声明式规则及独立内置模板；现有绑定和历史任务快照不会自动升级。

管理员任务详情分区呈现入站、归一化、模板准备、实际出站及上游响应，完整保留媒体正文和签名素材 URL，并记录 HTTP 状态、内容类型及文件信息。认证凭据和本地服务器路径仍保护。普通用户与安全预览继续使用原有保护边界。

新增素材映射表单、响应路径和状态转换表单，补充字段提示、示例及配置说明。无需数据库迁移，价格继续来自渠道定价。

生产发布前只读核验记录见 `CHANNEL_VERIFICATION_CURRENT.json`；修复后的线上配置与预览验收另行记录，不把发布前实测当成修复后验收。
