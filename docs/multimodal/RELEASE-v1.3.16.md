# Sub2API v1.3.16

让图片、视频及音频媒体任务先在本站持久化，再由后台 worker 提交上游，统一通过标准任务查询和成品接口跟踪；同时简化管理员联调与文档在线测试，修复按绑定配置的素材映射校验。

- 管理端真实联调和标准客户端使用同一套任务创建、计费预留、后台提交及任务查询逻辑；本站持久化后立即返回 HTTP 202，不把本站受理误报为上游受理。重复幂等请求恢复原任务，不会自动重复生成。
- 任务阶段明确显示本站待提交、提交上游、上游已受理、生成中、成功或失败；上游明确拒绝时展示原因并按失败流程释放预留，结果不明确时保留原任务供核对。
- 按模型/账号/分组绑定映射图片等素材。标量字段可显式接收单张对象映射后的字符串；数量或字段形状不匹配时在创建计费任务前拒绝，不改变其他绑定的数组形状。
- 管理端与文档测试按请求和绑定、免费预览和估价、提交和状态、成品和账单组织；原始请求响应与诊断默认折叠。大图片免费预览使用独立有界超时，超时提示明确说明没有提交生成请求。
- 扩展受限的手动生产部署入口，允许显式选择立即切换；仍执行正式 Release 校验、备份、恢复演练、迁移门禁、数据容器保护与上线验证。
- 不新增数据库迁移。真实上游契约验证使用一次明确的单图视频生成并已完成；验证记录不包含供应商凭证。

验证和生产部署结果见 `VALIDATION-v1.3.16.md`。
