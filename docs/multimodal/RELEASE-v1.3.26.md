# Sub2API v1.3.26

合并上游 v0.2.23（`5af9afb588c4b014b3df9db7d4073af1f8ae01b6`），保留本项目多模态任务、渠道监控、独立文档与迁移后生产安全部署。

- 支持 GPT-6.2 Sol/Astra、Ultra Fast 分组策略与渠道倍率；现有分组的强制 Ultra Fast 默认关闭，已有价格覆盖继续生效。
- 纳入首字前流式超时换号、长流空闲计时、客户端取消、WebSocket、缓存 TTL 计费及刷新令牌原子轮换等上游修复。
- 保留图片/视频异步任务、协议模板、参数规则、结算、监控记录、模型广场和管理员操作保护。
- 六项新增数据库迁移使用本项目编号 257–262；已执行历史迁移内容和校验和保持不变。Key 用量覆盖索引采用并发构建，新版和旧版镜像先在迁移后的隔离数据库中启动验证。
- 生产继续使用非 root、只读文件系统和最小能力镜像；来源 IP 审计、黑名单、已轮换 Key、Nginx 和防火墙由宿主机保留。

发布前的历史真实多模态案例明确保留为 v1.3.24/v1.3.25 基线，不声称已在新版重新生成。新版生产切换后仅执行预算不超过 1 美元的真实文本验收；图片与视频本轮使用隔离测试。完整仓库测试、镜像验证、数据库恢复和新旧版兼容演练均由发布及部署流程门禁控制。
