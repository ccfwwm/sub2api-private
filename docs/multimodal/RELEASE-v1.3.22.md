# Sub2API v1.3.22

本版本修复 OpenAI 图片生成计费优先级错误：当渠道模型配置了按次或按图片价格时，系统此前可能先命中分组通用的 1K/2K/4K 图片价，导致渠道配置的单价被覆盖。

- 分组模型专属规则优先于渠道模型价格。
- 渠道模型 `per_request` / `image` 价格优先于分组通用图片价。
- 分组通用 1K/2K/4K 图片价继续作为未命中专属定价时的回退价。
- OpenAI 图片网关与普通网关图片计费入口保持相同优先级。
- 新增回归测试覆盖生产场景：渠道 `$0.70` 覆盖分组 4K `$0.04`，以及分组模型专属价覆盖渠道价。
- 未修改历史账单，也没有新增数据库迁移。

生产排查依据：生产 `usage_logs.id=3284901` 的请求使用模型 `gpt-image-2.5-sunburst-4k`，渠道按张价格为 `$0.70`，分组通用 4K 价格为 `$0.04`，旧代码实际记账为 `$0.04`。
