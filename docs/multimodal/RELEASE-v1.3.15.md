# Sub2API v1.3.15

修复多媒体文档和管理端的视频实际联调流程，并升级发布审计发现的易受攻击传递依赖。

- 能力目录中的可选列表或素材配置为空时，模型选择和参数表单仍正常渲染；覆盖 `Cannot read properties of null (reading 'length')`。
- 图片、视频和音频素材可多选上传、分批追加或直接拖入；按目录检查类型、数量及文件大小，并可逐项移除。
- 管理端联调支持免费预览参数映射与估价，再明确确认后提交真实请求；保留幂等 ID 和同任务恢复查询。
- 显示真实任务的请求映射、提交/上游响应及日志，并可预览或下载生成的图片、视频和音频。
- 将传递依赖 `decode-uri-component` 固定为 `0.5.1`，修复审计发现的高危 URI 解码拒绝服务公告。
- 不新增数据库迁移；不自动发起供应商生成。

验证和部署结果见 `VALIDATION-v1.3.15.md`。
