# 三个访问入口的页面加载优化

2026-10-16 排查 `code.aicodeme.cn`、`code.aicodeme.xyz`、`hkcode.aicodeme.xyz`。主机负载约 0.23，应用 CPU 约 1%，应用本机 `/home` 响应约 41 毫秒，公开设置约 7 毫秒，未发现应用或数据库负载导致的数秒排队。

页面把设置中约 169 KB 的 Base64 PNG Logo 同时嵌入启动 JSON 和 favicon，导致每个 SPA 文档达到 354,479 字节，gzip 后仍约 272 KB。公开设置重复携带同一图片，响应为 184,547 字节。当前 Nginx 默认只压缩 HTML，Vite 的 JavaScript 和 CSS 缺少压缩；实测 Vue 公共脚本未经压缩传输 114,252 字节。跨境链路、Cloudflare 与香港转发增加连接和首字节时延，放大了这些响应体的下载成本。

v1.2.10 将有效的内联光栅 Logo 改为同源、按图片 SHA-256 命名的公开资源，页面启动 JSON、favicon 和公开设置共用这个地址。图片保留原始字节，浏览器可独立长期缓存；内容改变后地址改变。公开资源提供 ETag/304、HEAD 和不存在地址的 404。管理员原有设置及原始图片不改写，外链、相对路径及不支持的数据格式保持原有行为。

Nginx 只在现有两个 Sub2API HTTPS 虚拟主机插入专用压缩片段，开启 HTML、JS、CSS 等内容的 gzip 和 Vary；API 的既有 gzip off、流式缓冲设置及其他虚拟主机保持原样。脚本先备份配置，语法检查后平滑重载，失败恢复原文件。香港入口从源站获得同样压缩后的页面和静态资源。

发布采用本地构建及镜像上传。无需数据库迁移，不提交收费生成测试，沿用 v1.2.9 的实际媒体接口核验记录。验证包括公开配置与 HTML 的体积、Logo 原始字节和缓存行为、静态文件压缩、三个入口的实际响应与浏览器加载情况，以及生产数据容器、文档和价格的保持情况。
