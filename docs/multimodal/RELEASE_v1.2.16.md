# v1.2.16 模型广场与媒体配置修复

本版本修复模型列表因旧媒体绑定返回 HTTP 409 的问题，并改进管理员媒体配置和模型广场的故障隔离。生产切换是独立的手动操作；正式发布本身不代表生产已升级。

## 修复内容

- 兼容旧媒体素材映射。素材字段不再参与通用字段重命名规则；将历史 `image -> image.url` 规范化为模板素材目标，避免规则冲突导致 `/v1/models` 返回 `parameter_rule_conflict`。
- 模型广场按分组隔离媒体目录读取错误。单个分组不可用时，其他可用模型仍可展示；管理员诊断关联请求 ID 和失败分组，公开响应不包含内部诊断信息。
- 管理员媒体页面增加侧边栏入口，分区管理账号模型、协议模板、请求能力、诊断和任务；支持账号深链接定位。
- 账号模型列表可一键同步并幂等合并。新增模型默认为未绑定、未启用；已有绑定、模板、能力和启用设置不会被同步覆盖。
- 请求能力和账号覆盖配置提供表单编辑。媒体页面只读展示按公开模型名称匹配的渠道价格状态，不再另行维护媒体价卡。
- 上游模型发现按 `Retry-After` 处理 429 限流，避免把短时限流误报为模型永久不可用。

## 数据与发布边界

本版本不增加数据库迁移，不修改现有渠道价格和账务记录。模型价格仍由渠道定价配置，媒体设置仅显示匹配结果。新同步模型保持未绑定、未启用，需管理员完成模板和能力配置后再启用。

## 验收状态

- 源码与自动化测试：以本版本发布工作流和随版本保存的本地验证记录为准。
- 生产版本：部署前仍为 v1.2.15；模型列表、管理员媒体页面及媒体中转链路的生产复测须在 v1.2.16 成功切换后完成。
- 直连上游媒体测试不等同于 Sub2API 中转、价格匹配或账务验收。详细范围和待验证项见 [CHANNEL_VERIFICATION_CURRENT.json](CHANNEL_VERIFICATION_CURRENT.json)。
