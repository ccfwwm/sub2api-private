# Sub2API v1.3.12

修复协议模板日常操作、媒体模型测试展示和文档联调体验。

- 协议模板支持直接新增、修改标题和介绍、保存、复制为独立模板及删除。界面去除模板版本、历史备份和审阅发布流程；保存更新当前模板，不创建额外备份记录，并防止过期编辑覆盖最新内容。
- 删除模板后解除关联并停用引用模型，避免继续发送未配置协议的请求。已受理任务保留提交时的执行快照；历史存储格式与旧接口保留兼容。
- 预览与真实测试填写中转 API Key，无需查询数据库 Key ID；检查有效 Key、用户和真实分组范围。
- 媒体账号新增与编辑使用宽幅弹窗和响应式模型卡片，完整显示公开模型与上游映射。测试事件、请求摘要与结果同时展示公开模型和实际发送的上游模型，回归测试验证中文及特殊字符映射原样发送且仅提交一次。
- 管理端联调和公开文档支持多图片、视频、音频文件多选、分批追加、逐项移除、MIME/大小/数量检查及本地 Base64 转换。
- 文档在线调试自动载入公开模型目录，输入中转 Key 后自动加载可调用模型，提供明确空列表和错误说明；增加不生成的参数校验与估价、脱敏请求日志。
- 新媒体模型默认并发 100、查询间隔 10 秒；新媒体账号默认并发 100。无新增数据库迁移，部署时将现有媒体模型执行配置同步为用户指定默认值，保留后台 worker 配置。
- 包含 v1.3.11 之后的视频原文件下载修复：区分任务轮询与视频 content 路径。

已完成组件测试、前端类型检查与生产构建、Go 定向测试和 lint、隔离 PostgreSQL 模板 CRUD，以及桌面/手机浏览器操作验证。发布流水线继续执行完整单元、集成、镜像启动与备份恢复演练。发布前只读检查现有成功视频和公开制品 Range 206，未新增付费生成；不将模拟上游验证描述为真实供应商生成验收。
