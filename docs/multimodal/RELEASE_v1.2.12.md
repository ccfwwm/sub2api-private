# v1.2.12 媒体接口与任务核对

- 渠道检测异步提交并持久化幂等键，响应丢失后仅恢复查询；分别检测 gpt-image-2 与 gpt-image-2.5。媒体超时独立于文本请求。
- 完整 HTTP 503 作为明确失败处理，自动释放预留；网络中断、408、其他不明确 5xx 继续保留原任务，避免重复生成。
- 管理员可对所有媒体任务选择失败或已完成，再选择退回全部、最终扣费金额或保留实收。金额是最终净实收而非追加金额。保留原账本，使用版本及幂等保护。
- 管理员可读取最新详情、脱敏导出、预览下载原文件。播放凭证限定管理员、任务和产物，5 分钟有效；支持 Range 与 HEAD。
- 补齐图片编辑 JSON URL/data URL/文件/遮罩、Gemini 模态、视频素材及音乐请求；URL 专用协议提交前拒绝不支持的素材。
- 新增 API Key 能力查询与原任务恢复接口。
- 独立文档容器改为仓库维护的单一内容源，按五类接口提供文档、输入、输出、在线调试。默认浅色，兼容深色和手机。删除后台编辑与版本发布入口，保留历史表及迁移。

## 验证

媒体及路由测试、管理员下载权限与 Range 测试、独立 PostgreSQL 完整媒体集成测试、渠道检测重启恢复与双模型测试、前端类型检查/国际化/构建、文档请求构造测试与浏览器响应丢失恢复测试。

部署只更新应用与文档镜像，保留 PostgreSQL、Redis、历史账务和旧迁移。生产配置修改与历史 503 核对前单独备份。真实生成以最小规格记录任务、费用与文件校验。
