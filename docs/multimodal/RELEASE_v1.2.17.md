# v1.2.17 媒体请求与管理流程修复

本版本修复稳定配置下能力 profile 随请求变化导致的估价 400 / 提交 409，并修复管理员账号测试错误判断配置已变更的问题。生产切换和实际成品验收独立记录于 `PRODUCTION_ROLLOUT.md`。

## 请求修复

- 解析账号字段映射时按字段名稳定排序。相同模板版本、模型及账号配置产生相同的能力版本和公开 profile；真实配置变更仍使旧估价失效。
- 账号生成测试、异步轮询、进程重启恢复与结果查询统一比较解析后的固定模板版本。配置确实变化时停止原任务后续执行，不重新发送生成请求。
- 保留提交前持久化、任务身份和不确定请求不自动重提的机制。

## 管理流程

- 媒体管理保留账号模型、协议模板、联调检测、任务记录四个分区。模型绑定在账号模型内完成；旧绑定深链接仍定位指定账号。
- 账号模型先选分组再选账号，默认加载可用账号，支持页外账号深链接。账号、模板、定价等独立读取失败时局部显示错误。
- 联调检测提供分组、账号、模型和请求操作下拉列表；API Key ID 仍由管理员指定。预览携带明确账号和分组，不创建生成任务。
- 协议模板列表支持名称搜索、类型和发布状态筛选，显示固定版本、中文状态及结构化编辑区；专家 JSON 保留于高级区域。
- 价格仍按公开模型名匹配渠道定价，分组价优先、显式零价有效，不增加媒体独立价卡。

## 数据与验证

本版本没有新增数据库迁移。Go 单元测试、337 项独立数据库集成测试、前端 lint / 类型检查 / 构建及媒体组件回归已验证；异步固定模板回归额外覆盖原任务轮询恢复与只发送一次生成请求。

生产旧版本的连续免费测试中，同一视频模型 12 次能力查询出现两个 profile；6 次估价为 200 三次、400 一次、409 两次。本次发布后须重新验证 profile 稳定和估价结果，不将上述复现当成修复后结果。

ZeroWall Science 的 videos 0.2.6、ai-cloud 0.1.34 与 media-create 技能同步适配 profile 更新和错误类型，保留模型、参数、参考素材及请求身份。插件源代码已提交并生成带 SHA-256 的归档；它们是独立资源，本 Sub2API 发布不代表 ZeroWall 桌面运行实例已安装新插件，也不代表独立资源 feed 或桌面安装器已发布。
