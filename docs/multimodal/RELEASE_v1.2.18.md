# v1.2.18 媒体预览、导航与历史记录修复

账号测试中的图片、音频和视频支持同源受保护产物及绝对地址的认证读取。读取或浏览器解码失败时保留已完成任务，显示错误、下载与“重试预览”；重试只读取原产物，不重新生成。关闭弹窗后到达的读取结果不会重新占用预览资源，外部产物地址不携带管理员认证信息。

管理员侧栏增加“媒体能力”分组，可直接进入账号模型、协议模板、联调检测和媒体任务。旧 `tab=bindings` 账号深链接继续进入统一的账号模型编辑器。协议模板编辑保持现有发布、版本固定和二次认证规则。

用户侧栏恢复独立的“媒体任务”入口 `/media-tasks`，使用当前登录用户的任务接口，支持分页、模型、状态和密钥筛选；使用记录内原有媒体标签继续可用。个人媒体历史不再继承用量页面默认日期范围，历史任务不会因默认最近一天的统计范围而隐藏；管理员用量页仍可按日期筛选。

本次不增加数据库迁移。补齐媒体 CI 的 ffmpeg 依赖，修正媒体代码静态检查问题，保留提交未知任务不自动重提、原有权限隔离及渠道定价规则。发布前后的实际测试、镜像和切换证据独立记录于 `PRODUCTION_ROLLOUT.md`。
