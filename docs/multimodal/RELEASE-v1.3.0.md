# Sub2API v1.3.0

公开模型能力页面 `/media-capabilities` 按分组展示图片、视频和音频模型及生效售价，无需登录。专属分组沿用原有授权。管理员可在模型行编辑最多 2,000 字的纯文本说明；说明按分组和公开模型名保存，支持版本冲突检查、清空恢复默认，不改变模板、任务快照或价格。

音视频文档移至 `/media-docs`，登录后保留应用侧边栏，匿名访问提供公开导航。同源内嵌文档保留分类、章节、复制、客户端和自行填写 API Key 的联调；旧 `/docs/imagevideo` 入口保留。

管理员任务详情每 3 秒读取进行中的请求与响应记录，保留展开状态和核对草稿。Data URL 和 Base64 媒体正文显示摘要，HTTP(S) URL 与长提示词保留；普通复制使用摘要，完整审查导出仍保留媒体证据并保护认证信息。未记录的发送阶段明确标记。

普通用户可用登录会话预览和下载自己的图片、视频与音频，无需原 API Key。5 分钟访问票据限定用户、任务及产物，每次读取检查归属、用户状态和凭据版本；支持 HEAD、Range 和视频拖动。

无需数据库迁移，价格继续读取渠道定价。应用、文档和 Release 均公开发布。镜像完成校验后，通过宿主机管理器备份、隔离恢复演练，再使用显式 `--immediate` 立即切换；在途连接可能短暂中断。回退恢复应用与文档配置，不覆盖生产业务数据库。

发布前回归包含说明冲突、分组隔离、证据摘要、访问票据与 Range、任务刷新及用户三类预览、公开路由和旧 Nginx 片段升级。线上验收与镜像摘要在部署完成后另行记录。
