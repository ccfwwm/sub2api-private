# Sub2API v1.3.6

本版本包含媒体可用性检测、CC Switch 导入默认模型和账号分组目录加载修复，并记录了发布前生产渠道只读核验。

- 媒体生成检测失败会直接记为本轮失败，不再要求管理员确认或手动重置。明确拒绝的请求可在后续检测周期重新探测；已受理或受理状态不明的请求继续恢复或查询原任务，避免重复提交。
- CC Switch 导入默认值更新为 OpenAI `gpt-6.1-sol`。Claude 导入同时设置 `model` 和 `opusModel` 为 `claude-opus-5-5`。
- 账号页分组目录加载增加短暂失败重试，手动刷新也会重新加载分组，减少首次打开时分组缺失。
- 发布前只读请求 `GET /v1/models` 返回 HTTP 200 和 17 个模型；没有提交新的付费生成请求。脱敏结果见 `CHANNEL_VERIFICATION_CURRENT.json`。

本版本不新增数据库迁移。
