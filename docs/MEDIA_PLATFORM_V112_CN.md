# v1.1.2 媒体平台配置

媒体平台标识为 `imagevideo`，与 OpenAI、Gemini 同级。账号、分组、渠道和模型价格使用原有管理入口；不自动同步供应商价格，不需要建立来源或价卡模板。旧 `/admin/media` 地址跳转到渠道管理。

## 配置顺序

1. 在「分组管理」新增媒体分组，平台选择「媒体（图片 / 视频 / 音频）」。保留原有余额、套餐、权限与独立图片/视频倍率设置。
2. 在「账号管理」新增媒体账号，填写 Base URL、推理 API Key，并关联媒体分组。管理访问令牌用于测试平台管理接口，不能直接当作推理 Key。
3. 账号内「同步模型列表」只获取候选。选择模型后配置对应协议、精确上游 ID、时长、分辨率、素材限制和下载域名；不会自动启用模型、覆盖已填能力或修改价格。新模型时长默认为未验证，不猜测 30 秒。
4. 在「渠道管理」关联媒体分组并配置模型定价。也可以在分组内配置覆盖价格。模型 ID 区分大小写，保留 `/`；不支持通配符。价格与账号能力按同一模型 ID 关联，无需另选模板。
5. 记录真实渠道测试日期和结果，再启用模型。没有有效能力或售价的模型不会出现在 Key 的 `/v1/models` 列表里。

## 模型定价

在原有模型价格条目中选择媒体平台，可配置按次、成功产物、秒、分钟、真实 token，以及参考素材附加费。可增加组合收费项及按分辨率、尺寸、质量、场景、时长和音频开关匹配的价格档。

- 金额使用 USD 十进制字符串；`0` 为免费，留空为未配置。最终扣款保留 8 位小数。
- 售价优先级为分组覆盖、渠道配置。缺价或档位不匹配时拒绝提交，不采用文本/Grok 默认价格。
- 秒数来源可选请求、模型固定时长、实际产物或上游计费用量；选择后可配置取整步长、最低数量、套餐和累进档。
- token 单价按每个 token 配置，例如每百万 token 2 USD 填 `0.000002`。用量字段在账号能力中明确映射；没有真实用量时保持待结算。
- 实际时长或 token 等未知用量必须设置有限最高收费或数量上限。用户收费不会超过任务创建时锁定的上限。
- 默认成功收费、失败释放。显式选择「受理费」才在确认受理后失败不退；模型广场会显示该规则。
- 图片/视频独立倍率替代普通有效倍率；媒体倍率和分时倍率各应用一次。查询、下载不重复收费，调价不会追溯改变已有任务。

上游成本在渠道原有「账号统计计价规则」区域单独填写。按账号/分组筛选匹配，不用售价替代成本。没有成本配置时显示未知，配置计算值显示估算，供应商对账后管理员才能标为核实。

## 用户与管理员界面

用户在模型广场查看已开放的接口、基础价格、单位、档位和倍率；使用记录中查看自己的任务、冻结/结算/退款金额和收费明细。

管理员在原使用记录页面查看媒体任务，执行查询核对、明确失败处理、退款和成本核实。任务与原价格/能力快照保存在数据库，应用重启和客户端停止轮询不会丢失任务。供应商凭证不出现在用户账单里。

本轮新增供应商费用 0.352466 USD，累计 5.540890 USD。其他真实模型/场景证据见 [真实渠道验收](multimodal/REAL_CHANNEL_VALIDATION.md)。`00sd2.5`、`LLseadanco2.5` 不在当前测试 Key 可用列表内，不能标为真实生成通过。

测试凭证、能力和测试价格仅保存在本地隔离环境，不导入生产。生产发布新增 244/245 两个可空 JSONB 字段，先备份并在副本演练；保留历史数据及旧任务快照，只更换应用容器。
