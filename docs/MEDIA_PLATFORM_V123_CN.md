# Sub2API v1.2.3：ZeroWall 媒体能力适配

本版基于私有 v1.2.2，新增登录后只读的 `GET /api/v1/media/capabilities?group_id=<id>`。沿用现有用户分组权限、启用状态、模型白名单和有效售价判断，返回公开模型、操作及参数限制。不同能力配置分别返回；不会创建 API Key、预留费用或公开供应商凭据、绑定账户、成本及内部地址。

生成和费用估算可传 `public_profile_id`，精确选择目录中的配置。选择过期、跨分组或参数不匹配会拒绝执行。新增 `GET /v1/tasks/:id`，复用现有任务归属校验；下载和原有图片、视频、音乐接口保持兼容。GPT 图片编辑补齐 PNG mask 验证。

本版不新增数据库迁移。正式标签通过现有 Private Release 工作流执行 Go、前端、安全、规格、部署工具测试，构建固定 digest 镜像、隔离启动和恢复演练后发布。自动部署继续先备份与恢复验证，只替换应用容器，失败回退程序而不覆盖数据库。

本次发布清单明确复用 v1.2.2 中已有真实渠道制品证据，不把它描述为新生成。新能力接口、任务恢复和 ZeroWall 最小付费媒体样例在部署完成后另行验收；其任务、费用、文件大小、SHA-256 和实际时长记录于 ZeroWall 的交付收据。

ZeroWall 桌面维持 8.1.3。Account、AI Cloud、Images、Environment 与 oh-story 独立更新。登录只发现能力和配置分组 Key，媒体生成仍需用户触发；当前没有配音模型时保持不可用状态。
